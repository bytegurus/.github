# ByteGurus

Software engineering studio in Türkiye. Multi-tenant .NET platforms, payment and custody systems, and the mobile apps that sit on top of them — designed, built and run on Kubernetes.

[bytegurus.io](https://www.bytegurus.io) · [Services](https://www.bytegurus.io/services) · [Projects](https://www.bytegurus.io/projects) · [Blog](https://www.bytegurus.io/blog) · [Türkçe](https://www.bytegurus.io/tr)

## What gets built here

| Platform | What it does |
|---|---|
| [Custody Banking Platform](https://www.bytegurus.io/projects/custody-banking) | Custodian workflow between portfolio management companies and their banks, off spreadsheets and into one auditable system |
| [Payment System](https://www.bytegurus.io/projects/payment-system) | One API in front of many payment service providers, 3-D Secure included |
| [Subscription Management](https://www.bytegurus.io/projects/subscription-management) | Plans, trials, invoicing, dunning and revenue recognition for SaaS and OTT |
| [Enterprise IAM](https://www.bytegurus.io/projects/iam-system) | OpenID Connect, OAuth 2.0, MFA, SSO and LDAP/AD federation as a single identity plane |
| [Tenant Server](https://www.bytegurus.io/projects/tenant-server) | Organization hierarchies, per-tenant configuration and permissions for multi-tenant estates |
| [Notification Server](https://www.bytegurus.io/projects/notification-server) | Email, SMS, push and in-app behind one API with templates and delivery tracking |
| [FiyolaShorts](https://www.bytegurus.io/projects/fiyola-shorts) | Vertical short-form OTT: encoding, distribution and native mobile playback |
| [E-Commerce Platform](https://www.bytegurus.io/projects/ecommerce-platform) | B2C, B2B and marketplace models on one product, order and vendor core |
| [PKCS Smart Card Systems](https://www.bytegurus.io/projects/smart-card-systems) | PKCS#11 middleware for hardware-backed authentication and digital signing |

## How it is built

- **Backend:** .NET 8, gRPC, Entity Framework Core, PostgreSQL, Redis, Kafka (outbox pattern), Keycloak
- **Mobile:** Swift on iOS, Kotlin on Android, shared design-system libraries
- **Web:** Next.js, Astro, TypeScript, Tailwind CSS
- **Platform:** Kubernetes, Helm, Terraform, ArgoCD, Cloudflare, Elasticsearch

Contracts live in Protobuf; every service ships with `buf` codegen, EF migrations and licensing built in.
